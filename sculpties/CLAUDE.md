# Instructions for Claude: wiring the 3D sculptie pieces into the game

Read this before changing `piece.lsl` / `game_controller.lsl` to render the 3D
sculptie pieces in `sculpties/`. These maps were generated by the sibling
`../sculptie-test` repo (`make_sculptmap.py`); the geometry is fixed — your job
is the LSL render layer and per-type metadata.

## How sculpties differ from the flat textures

A sculptie is the prim's **shape** (`PRIM_TYPE` → `PRIM_TYPE_SCULPT` + map UUID +
stitching type), not a face texture. `piece.lsl` already supports this: when a
cell's type has a non-empty `SCULPT[type]`, render it as a sculpted token instead
of a flat textured tile. Owner **tint** is still `PRIM_COLOR`; **facing** is a Z
rotation of the prim; **glow/label** stay as-is. The flat `TEX` path remains the
fallback for any type whose `SCULPT` entry is `""`.

## Per-type requirements (index = piece type; see `../sculptie-test/README.md`)

| # | Type | Map file | Stitching | Directional? | Notes |
|---|------|----------|-----------|--------------|-------|
| 1 | King | `king_sculptmap` | Cylinder | no | tall; `SCULPT_SIZE` Z already raised |
| 2 | Laser | `laser_sculptmap` | Cylinder | **yes** | barrel points at the facing dir |
| 3 | Stunner | `stunner_sculptmap` | Cylinder | **yes** | octagon; 8 faces = `g-v-s-v-s-v-s-v` from the front (gun, then alternating vulnerable/shield). Front face = gun = the firing direction; keep `SCULPT_SIZE` X≈Y so the octagon isn't squashed |
| 4 | One-Way Mirror | `oneway_sculptmap` | Cylinder | **yes** | arrow; it points the **pass-through** direction. Keep `SCULPT_SIZE` X≈Y so the arrow stays proportioned (a flatter Z reads as a marker) |
| 5 | Triangular Mirror | `trimir_sculptmap` | Cylinder | **yes** | right triangle, reflective face = hypotenuse (front), right-angle vertex at back; keep `SCULPT_SIZE` X≈Y |
| 6 | Bomb | `bomb_sculptmap` | Cylinder | **yes (config)** | 4 blast spikes point at the orthogonal faces (explosion sides, default `bombDiag=0`). When `bombDiag=1`, rotate the prim an extra **45°** so the spikes point at the diagonals. Keep `SCULPT_SIZE` X≈Y |
| 7 | **Hypergon** | `hypergon_sculptmap` | **Sphere** | no | the ONLY Sphere-stitched piece — see required change below |
| 8 | Beam Splitter | `splitter_sculptmap` | Cylinder | **yes** | diamond; splitting edge faces forward |
| 9 | Partially-Mirrored Octagon | `poct_sculptmap` | Cylinder | **yes** | thicker shield on the 3 rear faces |
| 10 | Fully-Mirrored Octagon | `foct_sculptmap` | Cylinder | no | flat face toward each of the 8 facings |

Hole/Hyper Hole (11/12) have no sculptie — leave their `SCULPT` entries `""`.

## Required code changes

1. **Fill `SCULPT` UUIDs.** Upload each `*_sculptmap.png` to SL **with "Use
   lossless compression"** (lossy artifacts warp mirror facets). Record the UUID
   in `sculpties/uuids.txt`, then paste it into the matching `SCULPT[type]` slot
   in `piece.lsl`. King (1) and Full Oct (10) are already done.

2. **Per-type stitching (mandatory).** `piece.lsl` currently has a single
   `integer SCULPT_STITCH = PRIM_SCULPT_TYPE_CYLINDER`. Hypergon needs
   **`PRIM_SCULPT_TYPE_SPHERE`**, so replace it with a per-type list and index
   it by type wherever the prim's sculpt params are set:

   ```lsl
   // stitching per type (0..12)
   list SCULPT_STITCH = [
       PRIM_SCULPT_TYPE_CYLINDER, //  0 unused
       PRIM_SCULPT_TYPE_CYLINDER, //  1 King
       PRIM_SCULPT_TYPE_CYLINDER, //  2 Laser
       PRIM_SCULPT_TYPE_CYLINDER, //  3 Stunner
       PRIM_SCULPT_TYPE_CYLINDER, //  4 One-Way
       PRIM_SCULPT_TYPE_CYLINDER, //  5 Triangular
       PRIM_SCULPT_TYPE_CYLINDER, //  6 Bomb
       PRIM_SCULPT_TYPE_SPHERE,   //  7 Hypergon  <-- different
       PRIM_SCULPT_TYPE_CYLINDER, //  8 Splitter
       PRIM_SCULPT_TYPE_CYLINDER, //  9 Part. Oct
       PRIM_SCULPT_TYPE_CYLINDER, // 10 Full Oct
       PRIM_SCULPT_TYPE_CYLINDER, // 11 Hole
       PRIM_SCULPT_TYPE_CYLINDER  // 12 Hyper Hole
   ];
   ```
   Then: `PRIM_SCULPT, SCULPT[type], llList2Integer(SCULPT_STITCH, type)`.
   (Add `| PRIM_SCULPT_FLAG_MIRROR`/`_INVERT` only if a map shows up inside-out.)

3. **Facing (directional pieces only).** The maps are modelled facing **+Y
   (north)**. Rotate the prim about Z by `SCULPT_ROT_SIGN * orient * PI_BY_TWO/2`
   (i.e. `orient * 45°`), consistent with the existing `TEX_ROT_SIGN` logic. Test
   one directional piece (e.g. Laser): if it points the wrong way, flip
   `SCULPT_ROT_SIGN`; if a specific map is upside-down, set its `SCULPT_FLIP`
   entry to 1. Truly non-directional pieces (King, Hypergon, Full Oct) don't
   care. **Bomb** is a special case: it has no per-facing art, but add an extra
   **45°** to its Z rotation when `bombDiag == 1` so its blast spikes point at
   the diagonals.

4. **Sizing.** The maps encode positions in the `[-1,1]` box, so `SCULPT_SIZE`
   is just the prim's bounding box; axes the model doesn't fill stay
   proportionally smaller (that's how One-Way stays a thin panel). Tune
   `SCULPT_SIZE` / `SCULPT_BASE_Z` per piece for how it sits on the tile.

## Don't

- Don't edit the `*_sculptmap.png` files by hand — regenerate from
  `../sculptie-test` (`python3 make_sculptmap.py <shape>`) if a shape needs to
  change, then re-upload (new UUID).
- Don't reuse a `TEX` (flat sprite) UUID as a `SCULPT` UUID — they are different
  uploads.

## Verify in-world

Drop the updated `piece.lsl` into the cells and Reset Scripts. For each occupied
cell: the piece shows as a 3D token, tinted by owner, rotated to its facing
(directional pieces), with Hypergon rendering as a clean gem (Sphere stitch, not
pinched wrong). Empty cells stay flat tiles. Glow/`~STUN~` label still work.
