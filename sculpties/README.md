# Sculpties (3D piece models)

3D **sculpt maps** for laser-chess pieces — distinct from the flat top-down icons
in `../textures/`. A sculpt map is an RGB image whose pixels encode XYZ vertex
positions; SL drapes a prim's surface over them. Upload as a texture, then on a
prim set Building Block Type = **Sculpted**, drop in the map, and set the
**Stitching Type** listed below.

Generated by the dependency-free tool in the sibling `sculptie-test` repo
(`make_sculptmap.py`); regenerate with e.g. `python3 make_sculptmap.py foct`.

## Control panel buttons

Embossed icon buttons for the control panel — **not** game pieces (no owner
tint, not part of the `SCULPT` piece-type table). Each is a round button disc
with the symbol raised on top. Upload lossless, set **Stitching = Cylinder**.

| File | Button | Notes |
|------|--------|-------|
| `rotcw_sculptmap.png` | Rotate clockwise | circular arrow |
| `rotccw_sculptmap.png` | Rotate counter-clockwise | mirror of the CW arrow |
| `fire_sculptmap.png` | Fire | target reticle (ring + crosshair) |

Upload with **"Use lossless compression"** checked, or beam-reflection facets
will warp.
