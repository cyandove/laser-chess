# Piece textures

White, anti-aliased icons on a **transparent** background, **256×256** RGBA PNG, drawn
facing **north**. They're meant to be **tinted red/green per owner** in-world via
`PRIM_COLOR`, and **rotated** by the game to show the 8 facings — so one texture covers
every orientation of a piece.

Generated by `tools/gen_textures.py` (pure Python, no dependencies). To tweak a shape,
edit its function in that script and re-run:

```
python3 tools/gen_textures.py      # writes tex_*.png
python3 tools/preview_sheet.py     # writes _preview.png (white-on-dark contact sheet)
```

`_preview.png` is a review sheet only — don't upload it.

## Using them in Second Life

1. Upload the twelve `tex_*.png` (L$10 each). SL keeps the alpha channel.
2. Put each texture's UUID into the `TEX` table (see the `piece-textures` plan) — the
   game then sets the cell's texture by type, tints it by owner, and rotates it by
   facing.
3. Transparent background: the icon shows the owner tint; the gaps are see-through, so
   the cell's base/board shows behind the icon. If you'd rather have a solid tile, give
   the icons an opaque background at render time (or add one in the generator).
